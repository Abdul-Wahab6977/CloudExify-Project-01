## Deploy to Vercel

1. Push this folder to a GitHub repository (e.g. `cloudexify-web-p1-abdulwahab`).
2. Go to [vercel.com](https://vercel.com) → sign in with GitHub.
3. **Add New Project** → import the repository.
4. Framework preset: **Other** (static site, no build command needed).
5. Click **Deploy**. You'll get a live link like `abdulwahab-portfolio.vercel.app`.
6. Every future `git push` auto-redeploys.
